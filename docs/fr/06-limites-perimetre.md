# Chapitre 6 -- Limites et perimetre de ce parcours

Ce parcours couvre le README du depot (les trois skills recommandees et
leur installation), la structure generale de `build-on-base` (stack par
defaut, garde-fous de securite, table de routage par tache), le workflow
d integration des Builder Codes (detection de framework, ordre de
priorite), l onboarding et la regle de routage des plugins tiers de
`base-mcp`, et la configuration reseau ainsi que le mecanisme d installation
de `vibenet`.

Sont volontairement laisses hors champ : le detail de chacune des
references individuelles de `build-on-base` au-dela de leur simple mention
dans la table de routage (deploiement de contrat pas a pas, Base Account
SDK -- SIWB, sub-accounts, prolinks, abonnements --, enregistrement d agent,
operation d un noeud, et les guides de migration OnchainKit et
MiniKit-vers-Farcaster) ; les fichiers `plugins/*.md` individuels de
`base-mcp` (chacun documentant une integration tierce specifique comme
Aerodrome, Uniswap ou Morpho) ; et les references detaillees de `vibenet`
sur les cles de session et politiques, le sponsoring payer, et les comptes
EIP-8130 eux-memes, au-dela de leur mention dans le chapitre 5.

L objectif reste le meme que pour les parcours precedents de cette
bibliotheque : comprendre precisement comment ce depot structure des
instructions destinees a un agent IA plutot que du code d application, sans
pretendre couvrir l integralite d une collection de skills aussi etendue.

# Parcours francais : skills (Agent Skills pour construire sur Base)

Lecture pedagogique du depot base/skills : une collection de skills IA (au format agentskills.io) qui apprennent a un assistant a developper sur Base -- le playbook complet build-on-base, l acces wallet via Base MCP et ses plugins tiers, et l account abstraction native EIP-8130 de Vibenet.

Sommaire :

Chapitre 1 Presentation de base/skills. Chapitre 2 build-on-base, le playbook et le routage par tache. Chapitre 3 Builder Codes, attribuer et monetiser ses transactions. Chapitre 4 Base MCP, un wallet pour l agent et des plugins tiers gates par nom. Chapitre 5 Vibenet, account abstraction native EIP-8130 et sponsoring de gas. Chapitre 6 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
